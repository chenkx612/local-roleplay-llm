# morgana-v2 角色扮演后训练计划

## 项目目标

用一个角色、一个小模型和最小规模数据，走通可检查、可复现的后训练闭环：

```text
Persona 与数据 → Base → SFT → 前置 DPO 实验 → 规则型 GRPO
→ post-GRPO DPO → 统一评测 → 复盘
```

当前核心问题是：

> GRPO 已收紧可量化的客观下限，接下来能否用定向 DPO 改善主观语义质量，同时保持该下限
> 不回退？

项目坚持流程完整和简单快速：每个阶段只保留一组主配置、最小必要数据和可检查结论，不做大规模
调参或生产级平台建设。

## 质量标准

按以下顺序判断模型是否变好，不用单一总分掩盖底层失败：

1. **生成稳定性**：非空、完整、连贯、可读，无乱码、严重复读或破坏性截断。
2. **客观规则下限**：长度、自称、动作密度和硬格式等可验证规则不退化。
3. **主观角色质量**：身份、关系、视角和立场一致，能正确承接语义与情绪，表达自然。

GRPO 只负责前两项中的可量化部分；主观角色质量由人工偏好和 DPO 负责。Reward v2 不代表整体
角色质量，后续只作为候选过滤器和非回退门槛。

## 当前进度与决策

- **数据、Base 与 SFT 已完成**：冻结输入和评测集，SFT 已把不可用的 Base 提升到基本稳定可用。
- **前置 DPO 已留下负向结论**：多轮实验的人工结果持续低于 SFT，所有失败 adapter 只作历史
  证据，不进入后续链路。
- **规则型 GRPO 已完成**：`20260812-2144` 证明 Reward v2 具备连续、可排序的组内信号，并改善
  规则分和硬退化，因此停止继续扩展 GRPO；具体数据见 `RUNLOG.md`。正式人工复核仍保持待填写，
  不据此宣称主观质量已经通过。
- **post-GRPO DPO 数据已扩充并合并**：两轮独立采样均从 `20260812-2144` GRPO adapter
  出发，经 Codex 离线裁决后形成原始20对和扩充41对；训练入口固定合并为61对。首次合并训练
  `20260813-0124` 因更新过强和9条 Teacher chosen 语义矛盾而失败；Teacher 数据已重写。
  `20260813-0143` 使用 `2e-7` 后更新稳定且规则均分最佳，但仍未通过背景编造与生成稳定性门。
  v2 最终版固定使用 batch size 2、梯度累积1、学习率 `3e-7`、`rpo_alpha=0.1`。

## Post-GRPO DPO

本轮只优化三个从 Dev 诊断中选出的具体问题，不承担整体主观质量优化：

1. `fabricated_background`：无依据的背景人物、重大经历和共同记忆编造。
2. `perspective_shift`：把当前用户“莲”错当成对话外第三人等人物视角错位。
3. `emotion_response`：未准确承接用户明确表达的喜悦、歉意、失落等当下情绪。

- 两轮训练候选共使用90条新 Prompt，每题只标记一个目标问题；原始轮30条、扩充轮60条。
- 另留9条全新 holdout，每类3条，只用于 post-GRPO DPO 盲评。
- 原始轮每题采样6个候选，扩充轮每题批量采样8个候选；chosen 和 rejected 都必须通过 Reward
  v2 硬规则，且主要只在该题标记的语义维度上有差异。
- 当前合并61对：背景编造19对、视角错位19对、情绪承接23对，其中 Teacher chosen 为14对
  （22.95%）。两个源数据集及各自审计独立冻结，训练时按原始20对、扩充41对的顺序合并。
- 现有 Dev、Eval、holdout 和 `20260812-2144` 复核样本只用于评测，不得进入训练。
- 答非所问、过度顺从和一般语言自然度继续记录为观察项，但不是本轮训练目标。

DPO adapter 只有同时满足以下条件才能成为最终候选：

1. 人工盲评显示严重语义问题减少，角色一致性、语义承接和对话质量改善。
2. Reward v2、硬无效、退化和错误自称等客观指标不劣于 GRPO 起点。

## 收尾

最终统一评测在相同推理条件下比较 Base、SFT、GRPO 和 post-GRPO DPO；前置失败 DPO 仅作诊断
对照。完成统一评测和复盘，并为每个阶段留下最小可检查证据后，morgana-v2 闭环结束。
