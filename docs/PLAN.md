# morgana-v2 角色扮演后训练计划

## 项目目标

用一个角色、一个小模型和最小规模的数据，完整走通一次角色扮演模型后训练闭环：

```text
业务目标与 Persona
→ 数据准备与 Base 基线
→ SFT
→ DPO 可行性实验与负向结论
→ 从已验收 SFT 开始的规则型 GRPO
→ Base / SFT / DPO / GRPO 统一评测与诊断
→ 复盘
```

本轮只回答一个问题：

> 在 SFT 已完成行为打底、DPO 主观偏好实验留下可复核负向结论后，规则型 GRPO 能否从已验收
> SFT 出发，得到一版生成稳定、规则表现明确优于 Base 的 v2 模型？

项目优先保证两件事：

- **流程完整**：核心阶段不能省略，每一阶段都要留下可检查的输入、输出和结论。
- **简单快速**：每阶段只采用一组主配置和最小样本，不做超参数搜索，不建设生产级平台。

## 判断模型是否变好

按以下三个前置关系逐层判断，不用单一总分掩盖底层失败：

1. **生成稳定性**：回答非空、完整、连贯、可读，没有乱码、严重复读或破坏性截断。
2. **角色一致性**：在稳定生成的前提下，身份、性格、关系、边界、视角和整体语言风格符合
   Persona 及当前对话。
3. **对话质量**：在角色成立的前提下，回答自然、相关、有内容，并能支持对话继续。

动作括号、emoji、固定开头、自称频率和回答长度只用于诊断，不是优化目标。无外置记忆时，
也不要求模型机械复述固定事实。

## 核心流程

### 1. 数据与 Base

冻结 Persona、风格样例和 system prompt，建立彼此隔离的 SFT、DPO、GRPO、Dev、Eval 数据。
SFT 标签由 Student 先回答、Teacher 做最小必要纠错；随后用固定推理条件建立 Base Dev 基线，
供后续各训练阶段对照。

这一阶段的关键是：输入可追溯、数据无泄漏、标签可检查、Base 可作为后续公平对照。

### 2. SFT

在 Base 模型上完成一次固定配置的 QLoRA SFT，只学习 assistant 回复。训练后先验证参数确实发生
有效更新，再在同一推理条件下比较 Base 与 SFT。

只有 SFT 同时通过技术有效性、生成稳定性和匿名人工复核，才进入后续 DPO 或 GRPO。行为没有
改善时保留负向结果并停止，不在同一轮静默调参。

### 3. DPO

DPO 的目标是学习“可以稳定比较、但难以写成客观规则”的主观偏好。从通过验收的 SFT adapter
继续训练，通过人工校准的偏好对提升角色一致性、表达自然度、情绪回应和对话延续性，不把单次
大模型评分直接视为可靠真值。

生成稳定性是偏好数据的前提和训练后的回归门槛；能够自动验证的明确规则留给后续 GRPO。

DPO 负责探索提高回答质量上限的可行性。v2 已完成多轮数据和超参数实验，但匿名人工复核持续
低于 SFT，因此这些结果作为阶段性负向证据保留，所有失败 DPO adapter 均不得进入后续训练。
DPO 的数据扩充、目标函数和主观质量优化留到 v3，不再阻断 v2 的规则型 GRPO 闭环。

### 4. GRPO

当前 v2 从已通过验收的 SFT adapter 直接训练，不使用任何失败 DPO adapter。GRPO 只学习能够
稳定、自动验证的明确规则，例如不可读、严重复读、破坏性截断、明确身份错误和格式破坏。
角色感、语言自然度和情绪价值等主观目标不再由在线 Judge 提供奖励。

GRPO 负责收紧行为下限，而不是重新塑造整体对话风格。训练必须限制对 SFT 起点的偏离。v2 的
最低成功标准是技术训练有效、没有严重生成退化，并在冻结 Eval 上相对 Base 明确改善规则表现；
相对 SFT 的变化继续完整报告，但只作为诊断，不作为本轮强制阻断条件。

### 5. 统一评测与复盘

使用从未参与开发决策的 Eval，在完全一致的推理条件下生成 Base、SFT 和 GRPO 回答；失败 DPO
adapter 可作为诊断对照，但不作为最终候选。依次报告生成稳定性、规则违规、角色一致性和对话
质量，并保留代表性样本。

复盘分别回答 SFT 相对 Base、DPO 相对 SFT 为何失败、GRPO 相对 Base 和 SFT 发生了什么，同时
说明小样本、单角色、单次训练和偏好标注偏差带来的结论边界。

## 阶段决策

```text
数据与 Base 有效？ ─否→ 修复数据或链路
        │是
        ▼
SFT 技术、稳定性、人工复核均通过？ ─否→ 记录负向结论并结束
        │是
        ▼
DPO 可行性实验完成并留下结论？ ─否→ 完成实验与复核
        │是（当前为负向结论，丢弃失败 adapter）
        ▼
从已验收 SFT 运行规则型 GRPO
        │
        ▼
GRPO 技术有效、无严重退化且规则表现优于 Base？ ─否→ 记录负向结论
        │是
        ▼
统一评测 → 发布 v2 结论 → 复盘
```

## 完成定义

当数据准备、Base、SFT、DPO 实验、规则型 GRPO、统一评测和复盘都已执行，并各自留下可检查的
最小证据时，v2 闭环完成。GRPO 相对 Base 明确改善且无严重生成退化时，v2 模型达到本轮发布
目标；更高的角色自然度、情绪价值、高质量 SFT 扩充和 DPO 优化统一留到 v3。
